Multi-Device Cloud Sync (Google Sheets)

When participants scan the QR code on their own phones, paste your Google Apps Script Web App URL below so every phone automatically posts its score to your central Google Sheet.

How to setup Google Sheets sync in 60 seconds (free)
  1. Create a Google Sheet and click Extensions → Apps Script.
  2. Paste this snippet: 
    function doPost(e){
  var s = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var d = JSON.parse(e.postData.contents);
  s.appendRow([d.timestamp, d.name, d.contact, d.course, d.cwScore, d.muScore, d.quizScore, d.totalScore, d.totalTime]);
  return ContentService.createTextOutput("OK");
}
function doGet(){
  var rows = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet().getDataRange().getValues();
  return ContentService.createTextOutput(JSON.stringify(rows)).setMimeType(ContentService.MimeType.JSON);
}
  3. Click Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone) and paste the resulting URL above!
