Central Cloud Database (Firebase Firestore)

Real-time Multi-Device Sync

Connect free Google Firebase Firestore so every participant phone scanning the QR code synchronizes live scores to this admin dashboard and the auditorium projector screen instantly without refreshing.

How to setup free Firebase Firestore in 2 minutes (100% Free Forever)
  1. Visit console.firebase.google.com and create a project (Spark plan is 100% free).
  2. Go to Build → Firestore Database → Create database. Choose Start in test mode (or set rules for collection mhw_submissions).
  3. Click Project Settings (gear icon) → General → Your apps → Web app (</>).
  4. Copy your apiKey and projectId into the fields above and click Save Firebase Config.
  5. Done! All participant phones and auditorium screens are now synchronized in real-time.

Backup Cloud Sync (Google Sheets Webhook)

When participants scan the QR code on their own phones, paste your Google Apps Script Web App URL below so every phone automatically posts its score to your central Google Sheet spreadsheet.

How to setup Google Sheets sync in 60 seconds (free)
  1. Create a Google Sheet and click Extensions → Apps Script.
  2. Paste this snippet: 
    function doPost(e){
  var s = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var d = JSON.parse(e.postData.contents);
  s.appendRow([d.timestamp, d.name, d.contact, d.course, d.cwScore, d.muScore, d.quizScore, d.totalScore, d.totalTime]);
  return ContentService.createTextOutput("OK");
}
function doGet(){
  var rows = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet().getDataRange().getValues();
  return ContentService.createTextOutput(JSON.stringify(rows)).setMimeType(ContentService.MimeType.JSON);
}
  3. Click Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone) and paste the resulting URL above!
